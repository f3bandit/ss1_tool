# SS1 Tool NVMe drive list
#
# PCIe Gen 3 NVMe drives are safe in the SS1 dock; Gen 4 and newer cause sudden reboots, boot
# and file system problems. SS1 Tool reads the drive's own model name (through the dock's
# USB bridge) and matches it against these rules, top to bottom within each group.
#
# One rule per line:  gen3|gen4 <pattern>
# Patterns are case-insensitive extended regular expressions (grep -E). Keep them simple:
# letters, digits, spaces, ? + * [] () | and ^ $. SS1 Tool rejects the whole file if any
# rule doesn't compile, and then keeps using its built-in copy.
#
# Raise 'version' with every change: SS1 Tool uses the newest of its built-in list and this file.
version 1
