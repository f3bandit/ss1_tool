Setup
One-click fixes and installs for a SuperStation One.

 
Install SS1 scripts
Installs sd_integrity.sh, shutdown.sh and ss1_debug_report.sh into /media/fat/Scripts.

  

  
Community scripts
Downloads the latest version from the author's GitHub and installs it into /media/fat/Scripts. Run them from the MiSTer Scripts menu.

  

 
Samba file sharing
Enables the built-in Samba add-on at boot and starts it, so the card shows up in Windows as \\IP\sdcard.

  

 
Update All
Downloads the latest update_all.sh and sets downloader.ini to the MiSTer-devel main distribution with update_linux = false. That keeps your SS1 in a stable lane: cores and the menu still update, but the Linux kernel stays as it is, so a breaking kernel change can't force you to reflash your SD card. A backup of downloader.ini is kept.

  

  

 
Remove faulty overlap fix tool
Deletes fix_sd_overlap.sh / exfat_fix_overlap, which misdetect the correct SS1 layout as overlapping and can destroy the card (SuperStation-Documentation #14).

  

 
Console Mode scraper accounts
Writes your own ScreenScraper login and TheGamesDB API key to /media/fat/ConsoleMode. Leave a field blank to keep the current value.

WiFi setup
Create the WiFi settings file the SuperStation One uses (linux/wpa_supplicant.conf on its SD card), so it joins your wireless network when it starts.

 
Choose how to set it up

  

   
Option A: SD card in this PC

    
Use this if the SuperStation isn't on your network yet.

    
  1. Switch off the SuperStation and take out its SD card.
  2. Put the card in this PC's card reader.
  3. Pick your network and enter the password below, choose the card, and click Save to SD card.
  4. Safely eject the card in Windows, put it back in the SuperStation and switch it on. It joins WiFi as it starts.

   
Option B: over the network (temporary Ethernet)

    
Use this if you can plug the SuperStation into your router with an Ethernet cable for a few minutes.

    
  1. Connect the SuperStation to your router with an Ethernet cable and switch it on.
  2. Connect to it on the Connect tab, using the IP shown on its screen.
  3. Pick your network and enter the password below, then click Send to SuperStation.
  4. Click Restart SuperStation. When it's back, it's on WiFi. Note its new WiFi IP from its screen (or the status below), unplug the Ethernet cable, and reconnect SS1 Tool with that IP.

Games on the share
MiSTer looks for each system's games in this order and uses the first folder it finds: /media/fat/<system>, USB and NVMe drives (/media/usbN, then /media/usbN/games), /media/fat/cifs, /media/fat/cifs/games, and last /media/fat/games. So a system folder on the NVMe drive wins over the share.

How MiSTer maps controller buttons
When you remap a controller in the MiSTer menu (Define joystick buttons), MiSTer saves a mapping file in /media/fat/config/inputs, one for the menu and optionally one per core. Controllers without a mapping file use MiSTer's built-in controller database (linux/gamecontrollerdb). Your own controller profiles go in gamecontrollerdb_user.txt in the same folder.

SNAC controller (front ports)
The PlayStation controller in the SuperStation's own port 1, shown while Console Mode or MiSTer's menu is on screen. No PlayStation core or test ROM is needed.

  

  

  
Nothing lights up? First check the dock's SNAC Bypass switch is set to Disabled: SuperStations ship with it enabled, and while it is, the front ports are switched off and only the dock's SNAC port works. Then make sure Console Mode or MiSTer's menu is on screen, not a core: while a core runs, the core reads the port itself. If the controller doesn't move the cursor in the menu either, the menu isn't receiving it, so SS1 Tool has nothing to show. A controller that works in the PlayStation core with SNAC but not in Console Mode is a Console Mode issue: tell Retro Remake which controller or adapter it is.

Automatic updates:

  
SS1 Tool checks GitHub when it starts and every 6 hours. Updates come from the f3bandit/ss1_tool releases, are checked against the SHA-256 GitHub lists for the file, and replace SS1Tool.exe in its folder. The app restarts and this window switches to the new version by itself. Updates never start while a backup, restore, copy or SD card flash is running.

 
Window
SS1 Tool opens in its own window, with its icon on the taskbar like any other program. Closing the window keeps SS1 Tool running, with its icon by the clock, so long jobs like backups can finish and Linux update alerts still reach you. Click the icon to open the window again. Right-click it to turn Start with Windows on or off, or to Exit SS1 Tool completely.

  

 
❄ Winter mode
Adds falling snowflakes to the app during the snowy months (November to March). If animations are turned off in your Windows accessibility settings, this feature won't show.
