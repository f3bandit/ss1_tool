Install scripts and cores
Installs sd_integrity.sh, shutdown.sh and ss1_debug_report.sh into /media/fat/Scripts.

  

  
Memory card core
Installs the SS1 Memory Card Tool core in /media/fat/_Utility: it backs up and writes the PlayStation memory card in the front port. Files › Memory cards needs it. It shows in MiSTer's core list under Utility. SS1 Tool never installs or updates it by itself: that's this button.

  

  
Controller tester core
Installs the SS1 Controller Tester core in /media/fat/_Utility: it reads the PlayStation controllers in front ports 1 and 2, analog sticks included. Diag › SNAC controller tester needs it, and it works on its own from MiSTer's core list under Utility too. SS1 Tool never installs or updates it by itself: that's this button.

  

  
Community scripts
Downloads the latest version from the author's GitHub and installs it into /media/fat/Scripts. Run them from the MiSTer Scripts menu.

  





 
Update All
Downloads the latest update_all.sh and sets downloader.ini to the MiSTer-devel main distribution with update_linux = false. That keeps your SS1 in a stable lane: cores and the menu still update, but the Linux kernel stays as it is, so a breaking kernel change can't force you to reflash your SD card. A backup of downloader.ini is kept.

  

  





 
PSX SNAC settings
Sets which front ports the PlayStation core reads real controllers and memory cards from, right in its settings file (/media/fat/config/PSX.CFG). Every PSX core on the SS1 shares that file, Console Mode included. For real controllers in both front ports, SNAC has to be on for port 1 and port 2. Only these options are changed: all your other PSX settings stay as they are, and a copy of the file is kept in config/ss1tool_backup first.

SD card backup to the NVMe drive
The SuperStation copies its own SD card to the NVMe or USB drive, no PC needed. Everything except the games folder is copied: settings, saves, cores, Scripts, Console Mode, linux and so on. The next backup only copies what changed, so it's quick.

 
Back up now

  
The copy goes to SS1_backup/sdcard on the drive, with the same folders and file names as on the card, and is kept up to date: files you deleted from the card are removed from the copy too. To bring files back, copy them from there with the File manager. Avoid saving games or changing settings while it runs.

  

  

  

 
🌙 Nightly saves backup

  
Every night the SuperStation copies your saves and save states to the drive, into SS1_backup/saves/<weekday>, keeping one copy for each day of the week. It only runs while the SuperStation is switched on at that time, and keeps working after a restart.

Artwork
Box art and backgrounds for Console Mode, downloaded and sized on this PC instead of on the SuperStation, then copied over. Everything is kept in scrapes next to SS1Tool.exe, laid out like the SuperStation's folders, so the art can be put back after a reflash without downloading it again. Only pictures in the media folders are ever written or deleted: your games are never renamed, moved or deleted.

 
1. Your games

  

  
Reads the systems Console Mode knows and the games in their folders on the SD card and on USB/NVMe drives. In Console Mode, build the game database first so it lists the same games.

  

 
2. Download artwork

  

   
   

  

  

  

 
3. Results
Every game by system, with the art it has. For a patched, translated or modded game that wasn't found, type a simpler name (for example the original game's title), search, and pick a match: the art is saved under your game's own name (for a game in its own folder, the folder's name, as Console Mode expects) and copied to the SuperStation straight away. Your game files aren't renamed. Reload Console Mode to see the new art there.

  
Using your own picture (Upload)
    
   
  • File: PNG, JPG, GIF or WebP, up to 30 MB. It's saved as PNG under the game's own name, the way Console Mode expects.
    • 
   
  • Box art: the front cover, about 512 pixels on its longest side (for example 512×512, 512×720 or 720×512). Bigger pictures are fine: SS1 Tool also makes the 512×512 optimized copy Console Mode shows. Smaller than 256 pixels looks blurry on a TV.
    • 
   
  • Background: a screenshot or wide picture, ideally 16:9 like 1280×720; the game's own screenshot size (e.g. 320×240) also works.
    • 
   
  • Transparent parts show black in the optimized copy.

  

  
Find your games first.

 
4. Install on the SuperStation

  

  
Copies only pictures the SuperStation doesn't have yet (or that changed) into each system's media folder, on the SD card or the USB/NVMe drive the games are on. Console Mode shows new art after it reloads.

Finds pictures in the media folders whose game is no longer there, and lets you remove all backgrounds (Console Mode turns background downloads back on at every start). You see the list first; only pictures are deleted.

SNAC controllers (front ports)

  
Tests the PlayStation controllers in the SuperStation's front ports 1 and 2, and sets the PSX core's SNAC options, all from this card. SS1 Tool loads the controller tester core to read the ports: nothing is read until you start the test, and while it runs nothing you press reaches Console Mode or MiSTer's menu.

  

   ⚠ SNAC has to be on for both ports
   
The PSX core only reads real controllers (and real memory cards) in the front ports when SNAC is switched on for that port. Switch it on for port 1 and port 2 here, without loading the PSX core. Every PSX core on the SS1 uses these settings, Console Mode included. Only these options change, and a copy of the settings is kept first. More options (other controller types, presets): Setup › PSX SNAC settings.

   

    
    
    
    

  
How to use the tester
   
    
    
  1. Set the dock's SNAC Bypass switch to Disabled. SuperStations ship with it enabled, and while it is, the front ports are switched off.
    2. 
    
  2. Check the controller tester core's bubble next to Start says Core installed. If it says not installed or update available, click Install core / Update core. Check for updates asks GitHub straight away.
    3. 
    
  3. Plug your controllers into front port 1 and/or port 2, then click Start controller test. Whatever is on the TV closes, and the TV shows the test for both ports.
    4. 
    
  4. Pick Port 1 or Port 2 under Show. Press buttons and move the sticks: they light up here and on the TV. Analog controllers are switched to analog mode by the core; if the sticks still move the D-pad, press the controller's ANALOG button.
    5. 
    
  5. Click Stop when you're done: the menu comes back. Leaving this tab or page stops the test too.
    6. 
   

  

  

  

  

  
Nothing shows up? Check the SNAC Bypass switch first (step 1), and that the TV shows the test (if it doesn't, the core didn't start: click Start again). A controller that shows here but not in a PS1 game: make sure SNAC is on for that port (above) and reload the PSX core.

Supported Android versions

As Android moves on, a future update may raise the minimum version. Android versions below the new minimum won't be supported from then on: the version of SS1 Tool you have keeps working, but it won't get updates or fixes for them. A change to the minimum is listed in the release notes.

Automatic updates:

  
SS1 Tool checks GitHub when it starts and every 6 hours. Updates come from the f3bandit/ss1_tool releases, are checked against the SHA-256 GitHub lists for the file, and replace SS1Tool.exe in its folder. The app restarts and this window switches to the new version by itself. Updates never start while a backup, restore, copy or SD card flash is running.

 
Window
SS1 Tool opens in its own window, with its icon on the taskbar like any other program. Closing the window keeps SS1 Tool running, with its icon by the clock, so long jobs like backups can finish and Linux update alerts still reach you. Click the icon to open the window again. Right-click it to turn Start with Windows on or off, or to Exit SS1 Tool completely.

  

 
Updates
Steam keeps SS1 Tool up to date: updates download and install by themselves, like your games. Backups, saves and exports are kept in your Documents folder, in SS1 Tool.

 
✨ Seasonal mode
Adds a seasonal touch to the app: floating candles that drift, flicker and come and go, falling snowflakes, or twinkling stars behind the page, the odd meteor shower and, now and then, an aurora. Pick one and choose Always on, or Seasonal to show it only in its months. If animations are turned off in your Windows accessibility settings, this feature won't show.
